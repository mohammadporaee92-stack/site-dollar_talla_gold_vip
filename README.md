# طلا و ارز VIP — سایت نرخ لحظه‌ای دلار، طلا و سکه

یک سایت کاملاً **استاتیک**، **راست‌چین (RTL)** و **بدون وابستگی خارجی** برای نمایش نرخ
لحظه‌ای ارز، طلا، سکه و رمزارز، همراه با ماشین‌حساب تبدیل ارز و محاسبهٔ قیمت طلا.

- بدون فریم‌ورک و بدون build — فقط HTML، CSS و جاوااسکریپت خالص
- بدون فونت و آیکون CDN (روی اینترنت داخل ایران هم بدون مشکل باز می‌شود)
- قابل میزبانی روی GitHub Pages، Netlify، Vercel یا هر هاست سادهٔ دیگر
- همراه با تست خودکار (`node --test`)

## نرخ‌ها از کجا می‌آیند؟

سایت قیمت‌ها را به ترتیب زیر امتحان می‌کند و اولین منبع موفق را نمایش می‌دهد.
منبع و زمان آخرین به‌روزرسانی همیشه **پایین جدول** نوشته می‌شود.

| اولویت | منبع | حالت در رابط کاربری |
| --- | --- | --- |
| ۱ | کش مرورگر (کمتر از ۱۵ دقیقه) | «اتصال زنده (کش)» |
| ۲ | API زنده (فهرست `sources` در `assets/js/config.js`) | «اتصال زنده» |
| ۳ | `data/latest.json` (خروجی GitHub Actions) | «کش خودکار مخزن» |
| ۴ | `data/prices.json` (دیتای دستی داخل مخزن) | «دیتای دستی» |

### روش ۱ — کلید رایگان در مرورگر (سریع‌ترین راه)

1. از <https://brsapi.ir/tsetmc-exchange-free-bourse-api-key-request/> یک کلید **رایگان** بگیرید.
2. در سایت روی آیکون **چرخ‌دنده** بزنید، کلید را وارد و «ذخیره و به‌روزرسانی» را بزنید.
3. کلید فقط در `localStorage` مرورگر خودتان می‌ماند و به هیچ سروری فرستاده نمی‌شود.

### روش ۲ — گذاشتن کلید در فایل تنظیمات

در `assets/js/config.js` مقدار `apiKey` منبع `brsapi` را پر کنید.
(اگر مخزن عمومی است، بهتر است از روش ۱ یا ۳ استفاده کنید تا کلید منتشر نشود.)

### روش ۳ — به‌روزرسانی خودکار با GitHub Actions (پیشنهادی)

در این حالت GitHub هر ۳۰ دقیقه نرخ‌ها را می‌گیرد و در `data/latest.json` ثبت می‌کند؛
بنابراین حتی اگر مرورگر کاربر به دلیل **CORS** نتواند مستقیم به سرویس وصل شود،
نرخ‌ها تازه می‌مانند.

فایل ورک‌فلو به دلیل محدودیت دسترسی ربات (نداشتن مجوز `workflows`) در پوشهٔ `ci/`
قرار گرفته است. برای فعال‌سازی، یک بار آن را به مسیر اصلی منتقل کنید:

**راه ساده (از مرورگر):**
1. در GitHub فایل `ci/update-prices.yml` را باز کنید و محتوایش را کپی کنید.
2. `Add file → Create new file` و نام `.github/workflows/update-prices.yml` را بزنید.
3. محتوا را پیست و روی `Commit changes` بزنید.

**یا از طریق ترمینال:**
```bash
git clone https://github.com/mohammadporaee92-stack/site-dollar_talla_gold_vip.git
cd site-dollar_talla_gold_vip
mkdir -p .github/workflows
git mv ci/update-prices.yml .github/workflows/update-prices.yml
git commit -m "ci: فعال‌سازی به‌روزرسانی خودکار نرخ‌ها"
git push
```

سپس:
1. کلید رایگان را از لینک بالا بگیرید.
2. در GitHub: `Settings → Secrets and variables → Actions → New repository secret`
   با نام **`BRSAPI_KEY`**.
3. ورک‌فلو را یک بار دستی اجرا کنید: `Actions → CI و به‌روزرسانی نرخ‌ها → Run workflow`.

> ورک‌فلوها فقط روی **برنچ پیش‌فرض** زمان‌بندی می‌شوند؛ پس ابتدا PR را merge کنید.
> تا زمانی که ورک‌فلو فعال نشود هم سایت کار می‌کند و از `data/prices.json` یا
> کلید واردشده در مرورگر استفاده می‌کند.

### افزودن منبع دیگر

در `assets/js/config.js` یک آیتم به `sources` اضافه کنید:

```js
{
  id: "my-source",
  label: "منبع من",
  url: "https://example.com/prices?key={KEY}",
  apiKey: "",
  format: "brsapi",   // ساختار خروجی؛ در صورت تفاوت، normalize.js را گسترش دهید
  enabled: true,
}
```

اگر ساختار پاسخ متفاوت بود، کافی است در `assets/js/normalize.js` یک تابع تبدیل اضافه کنید.

## تست

```bash
npm test
```

تست‌ها شامل این موارد است:

- `normalize.test.js` — تبدیل پاسخ منابع (ساختار Pro و رایگان، واحد ریال/تومان/دلار، نماد تکراری)
- `calc.test.js` — تبدیل ارز، اجرت طلا، ارزش‌گذاری عیار، اسپرد
- `format.test.js` — ارقام فارسی، جداکنندهٔ هزارگان، تاریخ شمسی، «چند دقیقه پیش»
- `spark.test.js` — تولید نمودار کوچک
- `api.test.js` — کل مسیر آبشاری: منبع زنده، ردشدن منبع بدون کلید، CORS، HTTP ۴۰۳، کش، `latest.json` و `prices.json`
- `site.test.js` — یکپارچگی صفحه‌ها: ارجاع‌های شکسته، شناسهٔ تکراری، تگ بسته‌نشده، ترتیب اسکریپت‌ها
- `app-dom.test.js` — اجرای واقعی `app.js` روی `index.html` با یک DOM حداقلی: رندر جدول، فیلتر تب‌ها و جست‌وجو، تیکر، آمار هیرو، ماشین‌حساب‌ها، دکمهٔ کپی و فرم تماس
- `update-prices.test.js` — اسکریپت به‌روزرسانی خودکار

## انتشار روی GitHub Pages

1. PR را روی `main` merge کنید.
2. `Settings → Pages → Build and deployment → Source: Deploy from a branch`
3. برنچ `main` و پوشهٔ `/ (root)` را انتخاب و ذخیره کنید.
4. چند دقیقه بعد سایت روی `https://<username>.github.io/<repo>/` در دسترس است.

> برای مخزن **private**، GitHub Pages نیاز به پلن Pro/Team دارد؛ در غیر این صورت
> مخزن را عمومی کنید یا از Netlify/Vercel استفاده کنید (بدون تنظیمات خاصی کار می‌کند).
